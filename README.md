# UWJS-Project-1
The final project for a UW JS certificate first section. The idea is a website that lets you put in where you want to wing foil near Seattle, your experience level, and then gives you the current air temperature, wind speed, and a recommendation of whether or not to go.

API Key Usage: On line 4 of Index.js, paste the API key into the apiURLNoQuery variable where it says (API KEY HERE).

For usage guide on the API go to https://docs.apilayer.com/weatherstack/docs/api-documentation?utm_source=WeatherstackHomePage&utm_medium=Referral. 
 
Be careful, the API key gives only 100 free calls per month, at the time of presentation I anticipate the current monthly call number to be around 20.
